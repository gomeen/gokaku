输入习惯与候选窗外观确认页

在改正式输入法代码之前，用这一页确认候选窗外观、标点、Shift、大写字母、数字、方向键、分段选择、英文候选、按应用默认英文等看得见的变化。候选来自预生成数据，不是实时引擎。

可丢弃原型，候选来自预生成数据（libime 出厂数据的真实出厂顺序，未开启个人调频）。状态只保存在内存里，刷新即清空。页内无联网请求；英文候选与英文释义是手写示例数据。
检测到系统输入法正在组合输入。请先把系统输入源切到 ABC，再刷新本页用真实按键演示；否则按键会交给当前输入法，本页收不到。也可以只用屏幕按键和场景按钮。

模拟当前应用

中文

Raycast 与 VS Code 演示“按应用默认临时英文”；聊天与终端默认中文。每个应用各自保留已上屏文字。

点击正文区域后即可用键盘输入；物理键不方便时用下面的屏幕按键。

屏幕按键

浏览器里 Shift 单击按“按住期间没有其他按键＋按时长”判定，不代表真实 IMK 修饰键事件；真实实现的判定会在正式实现阶段另行验证。组合中另可用 Control＋a/e/b/f/n/p（行首尾／光标前后／候选上下），见「Ctrl 编辑键」场景。

按场景确认

每步用与真实按键相同的处理路径执行。切场景会重置演示状态；任何时候也可以自由输入。
