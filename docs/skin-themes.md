# 候选窗皮肤

原生界面按最后定稿的 [皮肤原型](../prototypes/skin-settings-demo.html) 实现；主题数据和共享契约已进入当前源码。原生设置、持久化与离屏渲染的历史验证证据见[验收记录](validation/skin-native-status.md)；真实输入源外观／热更新、性能及完整宿主验收仍未完成。

## 选择与编辑

设置新增「皮肤」页，提供 Gogaku、Claude、Grok Bot、女巫魔药，以及本机保存的自定义主题。选择只更新预览，点击「应用主题」成功写入后才改变输入法。列表不区分浅深两个选择槽：有深色配色的主题跟随系统，缺少深色配色时两种系统外观共用浅色配色。

顶部为「编辑当前主题」「导入主题…」「＋ 新建主题」；「编辑当前主题」打开正在使用的主题（当前为旧默认 `rime-macos-like`，或已应用主题失效回退到它时，打开 Gogaku），与列表选中项无关。列表下方为「应用主题」「编辑」「复制并编辑」，最后一个按钮对用户主题是「删除」，对内置主题是「恢复默认」：

- 「编辑」对所有主题可用。用户主题原地编辑；内置主题原地编辑并把相对出厂数据的差异存成覆盖补丁（见下）。
- 「复制并编辑」对所有主题可用，复制列表里看到的版本（已套用覆盖补丁）；结果是新的用户主题，名称为「原名 副本」。
- 「恢复默认」只在内置主题有覆盖时可用，确认后删除补丁。主题 ID 不变，正在使用则仍保持应用，外观回到出厂数据。

有覆盖的内置主题，列表副标题显示为「内置 · 已修改 · 单色／浅深双色」。

一级页面为左侧列表、右侧九条候选预览，中间竖线分隔。编辑在二级页面完成：左侧配置独立滚动，右侧固定预览；两级共用同一内容高度上限 800pt，默认窗口 1100×800pt，最小 1000×520pt。两列没有额外圆角容器背景，隐藏滚动条；预览与配色 Tab 间保留 24pt 间距。窗口较矮或字号较大时，预览列有独立滚动空间。

新建主题默认单色；编辑器支持增加深色配色，或保留当前配色改为单色。浅深切换同时切换该外观的颜色、形状、透明度与背景图；名称及字体由两种外观共用。

| 配置组 | 内容与范围 |
| --- | --- |
| 主题与字体 | 名称最多 128 字符；中文、英文字体填写本机家族名或 PostScript 名，`system-ui` 使用系统字体，找不到时回退系统；候选字号 12–24，序号字号 8–20 |
| 形状与间距 | 圆角 0–20pt，内边距 0–20pt，行高为 30pt 的 80%–140% |
| 背景与透明度 | 整体不透明度 40%–100%，背景色不透明度 0%–100%，背景图不透明度 0%–100%；本地背景图填充并裁切到候选窗圆角 |
| 颜色 | 背景、边框、候选文字、翻译文字、序号、高亮背景、高亮文字、选中时翻译文字、输入与光标、页码 |

内置主题也可以原地修改（2026-11-12）：编辑页内容全部可改，包括名称、字体、字号、形状、透明度、背景图、十种颜色，以及添加深色配色或改为单色。修改以差异补丁保存，补丁之外的字段继续跟随出厂数据，因此出厂数据更新后未被改动的属性会自动跟随。草稿与出厂数据完全一致的保存等于恢复默认（删除覆盖）。

编辑器只修改草稿。编辑正在使用的主题时保存按钮显示「保存并应用」，保存后立即生效（同一次写入完成；从 `rime-macos-like` 保存 Gogaku 后切换到新渲染方式）；编辑其他主题时显示「保存主题」，保存后不自动应用。已应用的用户主题保存后沿用原 ID，输入法重载时重新解析内容。返回、切其他设置页、关窗、退出共用未保存提示；保存或文件操作期间保护草稿。候选文字对纯色背景的对比度低于 4.5:1 时显示提示，透明或带图片时额外提醒检查实际可读性。

字号和形状按定稿原型属于皮肤属性。旧 `rime-macos-like` 设置仍使用历史渲染、全局 12–16 字号和无边框外观；选用新主题后使用主题字号。皮肤不改变每页九个、候选排序、翻页、选择或上屏规则。

## 分享与图片

列表提供「导入主题…」，编辑页提供「导出主题…」。导入经过完整校验后进入草稿，分配新用户 ID；保存后才加入列表，不能通过导入覆盖内置主题。导出包含当前草稿，无需先应用。失败显示具体错误，不报告保存成功或改变已应用设置。

`.gogakutheme` 为 ZIP，v1 只允许一个 `theme.json`：

```json
{
  "formatVersion": 1,
  "theme": {
    "id": "D6C838CC-2D24-4F03-982C-B2DA199D77A4",
    "name": "我的主题",
    "light": {
      "background": 16777215, "border": 14147545, "text": 2107685,
      "comment": 8214528, "index": 7897981, "highlight": 1218922,
      "highlightText": 16777215, "highlightComment": 16777215,
      "cursor": 5465434, "page": 8095872,
      "visual": { "radius": 8, "padding": 8, "rowHeight": 100, "opacity": 100, "bgOpacity": 100, "imageOpacity": 25 }
    },
    "typography": { "fontCN": "system-ui", "fontEN": "system-ui", "fontSize": 14, "indexSize": 11 }
  }
}
```

以上为可读取的单色清单示例；增加同结构的 `dark` 可成为双色主题，配色中的 `imageData` 为可选 PNG Base64 字符串。`typography`、`visual` 缺少字段时使用默认值。整数颜色取值 0–16777215；透明度由独立视觉字段控制。未知 JSON 字段由 Codable 忽略，未知格式版本拒绝。本轮以定稿原型的单／双色数据模型为准，图片内嵌在清单中，不解包到 themes 目录，不支持外置资源、字体文件、九宫格或平铺。用户主题在 `settings.json` 的 `userCandidateThemes` 中保存，选中 ID 为 `candidateTheme`。

内置主题的原地修改存为顶层字段 `builtinThemeOverrides`，键是内置 ID（`gogaku`、`claude`、`grok`、`witch`），值是相对出厂主题的 JSON Merge Patch（RFC 7386）：

```json
"builtinThemeOverrides": { "claude": { "light": { "highlight": 1218922 }, "dark": null } }
```

值为 `null` 表示删除该键，例如 `"dark": null` 把双色主题改为单色；为单色主题添加深色配色时补丁里写入完整的 `dark` 对象。补丁里的 `id` 一律剥除，不能改主题身份；输入法解析主题（Mac `Settings.resolvedCandidateTheme`、Windows `resolvedTheme`）都使用套用补丁后的内置主题，只有旧默认 `rime-macos-like` 始终使用出厂 Gogaku 配色与历史渲染。若补丁套用后的主题在本端解码／校验失败（例如字号超出范围），该内置主题回退到出厂版本，不影响其他设置；这与处理损坏用户主题的方式一致。补丁的规范化、合并与求差只在共享核心实现一份（`gc_themes_effective`／`gc_theme_override_make`，向量见 `shared/GogakuCore/tests/theme_contract_test.cpp`），两端只做 JSON 搬运与本端校验。背景图同样写入补丁，与用户主题的存储方式一致。

导入和选图在后台执行。只接受完整的单帧 PNG、JPEG、WebP；实际解码后转换为 sRGB PNG，去掉原图元数据。输入、转换后图片均不超过 8MiB，宽高各不超过 4096 像素。ZIP 读取限制文件大小 24MiB、清单 16MiB、声明展开总量 20MiB；校验本地头、中央目录、CRC、数据描述符，拒绝重复路径、路径穿越、符号链接、特殊文件、加密及不支持的压缩方式。只读取不可变快照中的唯一清单，不将路径展开到磁盘。

背景图在主题更新时解码并缓存，普通布局及绘制复用缓存。字体只引用本机字体；分享包不附带字体，主题图片的使用与分享授权由制作人自行确认。

## 配色来源与验证边界

Claude、Grok Bot、女巫魔药参考 [Mayoi theme.go](https://github.com/sorrycc/Mayoi/blob/bddd97f0788237d10a2e3ad06c211d5a1dbf4897/cmd/mayoi/theme.go)，按候选窗语义重新映射。Claude 浅色背景为 `#f5f4f1`，Grok Bot 为 `#f5f5f5`，均有独立深色背景；女巫魔药为单色。Mayoi 的 MIT 署名与许可随资源许可目录保存，见[第三方说明](third-party.md)。未引入第三方图片或字体文件。

本轮完成核心／持久化／格式与离屏渲染回归、隔离设置窗口检查。尚未安装此分支输入源，也未完成真实 IMK 宿主的热切换、背景图逐键性能和完整发布验收；设置中的九条候选是布局样例，不是翻译模型结果。
