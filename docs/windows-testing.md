# Windows 开发测试安装包

本页描述的安装包：`0.1.1-dev.2`，构建 `99`，dev 通道（2026-11-08 已在 Windows VM 默认升级安装）。支持 Windows 11 x64，安装包同时包含 64 位和 32 位 TSF；Windows ARM64 和 Windows 10 不在本轮支持范围。

**b98 修复三个真实输入缺陷并复测通过，b99 补挂起的恢复 Shift 点击；完整验收仍未通过。** b95 修跨字段旧提交资格；b97 修 InputScope 滞后吞首键（b96 密码轮 `ihc `）；b98 修调频落盘阻塞请求（b97 `hc你好` 重复出字）；b99 修默认英文应用的恢复 Shift 点击在会话就绪前丢失。b98 的 13 轮限定矩阵与 b99 的切框／密码／记事本无回归验证通过；VS Code／Electron 类宿主与 Windows Terminal（未安装）为受限项，安装回滚／卸载仍未完成。见[修复说明](validation/dev-b99-fix/README.md)和[汇总](validation/dev-b99-fix.json)。

这是标准 Inno Setup 安装向导 EXE，双击安装，不需要运行脚本或预装 Python、GCC、Visual Studio。可交付文件的路径、大小与 SHA-256 以[构包报告](validation/windows-setup-build.json)为准。

## 安装与启用

1. 将 `Gogaku-0.1.1-dev.2-b99-dev-windows-x64-setup.exe` 复制到 Windows，双击后按向导安装，并允许 UAC 注册输入法。当前包无 Authenticode 签名，系统可能显示未知发布者。
2. 安装完成后，在 Windows“设置 → 时间和语言 → 语言和区域 → 中文（简体，中国）→ 语言选项 → 键盘”中添加 **Gogaku Dev**。安装器不替换默认输入法，不修改系统显示语言；输入法列表未刷新时，可自行注销再登录。
3. 从开始菜单打开“Gogaku Dev 设置”，在任务栏输入法菜单或 Win+Space 中选择 Gogaku Dev，然后到记事本等空白文档输入。

从 b94 起，在输入法激活时启动代理，并最多等待 5 秒完成连接。b98 记事本两次代理缺席后的新进程首组均提交「你好」，b99 无回归验证同样通过；这不代表逐键性能或慢机启动门槛通过。若超时且代理仍不可用，按键可能交还应用；已经写入正文的拼音不会被自动回收或重放，请自行删除后重输，并反馈应用和构建号。本包仍是开发测试版。

普通输入默认小鹤双拼，可在设置改为全拼；英文候选与中文释义离线可用。每页 9 个候选，数字选词。按默认英文的应用可能先处于临时英文状态，单击 Shift 可切回中文。

从 b95 起，在 Chromium 等临时文本存储中仅用浮动候选窗显示编码，明确选词时再写入正文；宿主终止组合后重新分配字段身份，不把旧草稿提示或提交资格带到新字段。b97 起首次安全判定为「允许」时会短暂复核一次，避免宿主切换字段后 InputScope 滞导致密码字段首键被吞；无法确认原字段时不提供旧草稿恢复。原生持久文本存储继续遵循「输入区字母」设置。

模式快捷键默认 Ctrl+Shift+K，方向默认 Ctrl+Shift+J；托盘菜单提供等价入口。模式与方向在应用间保持全局偏好。

## 学习翻译与检查更新

学习翻译默认关闭。需要用户在“学习翻译”保存自己的火山 Access Key ID／Secret Access Key，点击连接测试，并显式启用学习翻译。普通输入不发送翻译请求。学习组合中 Ctrl+Enter 可明确原文上屏；失败保留源文，不自动改写正文。

版本旁“检查更新”打开独立窗口，自动检查默认关闭。此构建未配置实际 GitHub 发布仓库，因此会显示“未配置更新源”，不表示已是最新版本。

## 升级与卸载

安装器保留固定安装根，将程序和只读资源放入其 `versions\<版本>-b<构建>-<通道>` 子目录。新构建升级不覆盖旧宿主持有的 DLL；b94 至 b99 均完成默认升级，未再次指定旁置目录。新启动的应用使用新 DLL；已打开的应用可能继续使用旧组件，需要时请保存工作后重新打开。安装器不强杀应用、不自动重启。驻留旧版 DLL 的宿主（含系统进程）可能在管道空闲时按旧路径复活旧代理：新代理持锁期间僵尸秒退，不影响当前输入；旧宿主需重开后才会换用新 DLL。

同一构建重装和卸载仍要求释放相关文件；请先保存工作、切换到其它输入法，在 Gogaku 托盘菜单退出代理、关闭设置和使用过 Gogaku 的应用，遇到占用提示后按说明重试。注册失败恢复已实现，但完整故障恢复／卸载矩阵未验收；旧版本文件暂时保留，尚未自动清理。

在 Windows“已安装的应用”或开始菜单的卸载入口卸载。用户数据默认保留在 `%LOCALAPPDATA%\Gogaku`，包含设置、调频、自定义词、主题及单独保存的翻译凭据；dev／stable 共用这些数据。不要为重装直接删除该目录。
