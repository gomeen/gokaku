# Windows 开发测试安装包

当前构建：`0.1.1-dev.2`，构建 `91`，dev 通道。支持 Windows 11 x64，安装包同时包含 64 位和 32 位 TSF；Windows ARM64 和 Windows 10 不在本轮支持范围。

这是标准 Inno Setup 安装向导 EXE，双击安装，不需要运行脚本或预装 Python、GCC、Visual Studio。可交付文件的路径、大小与 SHA-256 以[构包报告](validation/windows-setup-build.json)为准。

## 安装与启用

1. 将 `Gogaku-0.1.1-dev.2-b91-dev-windows-x64-setup.exe` 复制到 Windows，双击后按向导安装，并允许 UAC 注册输入法。当前包无 Authenticode 签名，系统可能显示未知发布者。
2. 安装完成后，在 Windows“设置 → 时间和语言 → 语言和区域 → 中文（简体，中国）→ 语言选项 → 键盘”中添加 **Gogaku Dev**。安装器不替换默认输入法，不修改系统显示语言；输入法列表未刷新时，可自行注销再登录。
3. 从开始菜单打开“Gogaku Dev 设置”，在任务栏输入法菜单或 Win+Space 中选择 Gogaku Dev，然后到记事本等空白文档输入。

**已知限制：代理完全退出后的第一组输入可能不显示候选，直接留下拼音。** 本包不是稳定版；首次启用可先双击安装目录 `C:\Program Files\GogakuDev\bin\x64\GogakuAgent.exe` 启动代理，等待数秒，再到空白测试文档输入 `nihc`、按空格，确认得到“你好”后使用。遇到残留拼音请自行删除后重输，不会自动回收或重放已落入正文的按键。

普通输入默认小鹤双拼，可在设置改为全拼；英文候选与中文释义离线可用。每页 9 个候选，数字选词。按默认英文的应用可能先处于临时英文状态，单击 Shift 可切回中文。

模式快捷键默认 Ctrl+Shift+K，方向默认 Ctrl+Shift+J；托盘菜单提供等价入口。模式与方向在应用间保持全局偏好。

## 学习翻译与检查更新

学习翻译默认关闭。需要用户在“学习翻译”保存自己的火山 Access Key ID／Secret Access Key，点击连接测试，并显式启用学习翻译。普通输入不发送翻译请求。学习组合中 Ctrl+Enter 可明确原文上屏；失败保留源文，不自动改写正文。

版本旁“检查更新”打开独立窗口，自动检查默认关闭。此构建未配置实际 GitHub 发布仓库，因此会显示“未配置更新源”，不表示已是最新版本。

## 升级与卸载

当前安装器使用固定程序目录。升级或卸载前先保存工作、切换到其它输入法，在 Gogaku 托盘菜单选择“退出输入代理”，关闭设置和使用过 Gogaku 的应用。程序仍被 TSF 宿主占用时，安装器会中止并提示；用户可自行注销后重试。安装器不强杀应用、不自动重启。

在 Windows“已安装的应用”或开始菜单的卸载入口卸载。用户数据默认保留在 `%LOCALAPPDATA%\Gogaku`，包含设置、调频、自定义词、主题及单独保存的翻译凭据；dev／stable 共用这些数据。不要为重装直接删除该目录。

## 当前验证边界

已完成 Mac 交叉编译、PE 架构和系统依赖检查、Inno Setup 实际编译、包内容核对及共享核心关键回归。用户后续授权连接已安装的 Windows 11 VM，排查普通输入、候选窗、设置与图标；运行证据及各次失败保留在[原生验收记录](validation/native-development.md)。这只覆盖该 VM 的限定场景，真实火山、在线更新、完整宿主、升级／卸载和长时稳定性仍未验收。

设置已改为七项侧栏、固定页头／保存状态栏、DPI 缩放与微软雅黑 UI；皮肤预览在最小窗口仍完整显示九条。安装器、设置、代理／托盘与 TSF 随包图标资源，开始菜单设置入口使用随包程序图标。构建 90 修复旧连接迟到失焦通知清空当前组合的问题。构建 91 修复记事本 `RichEditD2DPT` 缺少 InputScope 时被拒绝输入；兜底仍核对焦点／文档归属、密码字符、只读与禁用状态，未知控件不放行。

[构建 91 运行证据](validation/windows-desktop-b91.json)包含记事本候选窗截图、五次后续输入“你好”、32／64 位合成 Edit 上屏、每架构 13 项兜底函数检查、63 个安装文件哈希和冷启动失败。安装前曾人工移动被旧宿主占用的文件，因此这次成功不代表普通升级／回滚已通过。

优先确认安装后能添加 Gogaku Dev、在 64 位应用正常输入、设置能保存重开，以及需要的 32 位应用能输入。反馈时提供版本／构建、应用名与位数、触发步骤及错误文字即可；不要发送翻译密钥或真实敏感输入。

当前尚有多候选预译、共享学习协调、随包 WebP codec、旧 `settings.txt` 迁移、历史片段管理、双通道调频并发和版本化升级恢复等实现缺口，详见[双端功能对照](feature-parity.md)。本包用于开发测试，不代表双端完整功能或正式发布已验收。
