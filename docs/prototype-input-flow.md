# 输入流程原型

本原型回答一个问题：选词即上屏能否与模式切换、用户英语输入的波浪线提示共存，而不增加一次翻译确认。

这是可丢弃的行为原型，不是正式界面或输入法实现。源文件为 [prototypes/input-flow.html](../prototypes/input-flow.html)，无第三方依赖。需求依据仍是[产品方向](product.md)。

## 体验方式

直接用浏览器打开 HTML。macOS 可以在项目目录运行：

```sh
open prototypes/input-flow.html
```

如果浏览器工具限制访问本地文件，可以只在本机提供静态页面：

```sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory prototypes
```

随后访问 `http://127.0.0.1:8000/input-flow.html`。命令运行期间页面才可访问，结束后按 Ctrl+C 停止服务。原型本身不依赖服务器或联网服务。

页面上半部分模拟当前应用，下半部分是 Gogaku 未提交输入与候选。它们放在同一页面用于观察提交边界，并不意味着正式产品需要打开两个编辑区。

可以自由输入，也可以点击下方场景并逐步体验。切换场景会重置整个演示状态。

- Enter 选择首个候选并直接上屏，没有二次翻译确认。没有候选时不猜测、不提交。
- 英语词后输入空格或标点，才对预设问题词显示波浪线。点击原词只显示说明，不替换。
- 「原文上屏」是明确选择保留原文的入口。「取消当前输入」只清空当前输入。
- 模式菜单支持普通与学习模式切换，学习方向另设菜单。
- Ctrl+Shift+K 在本页模拟模式切换，不是正式 macOS 快捷键方案。
- 聊天和笔记是两份页面内状态，分别保存模式、方向、草稿和模拟上屏内容。切换模式或方向时，未完成输入留在原状态，切回可恢复。这是待体验的方案，不是已确认的原生实现。

自由输入样例列在页面右侧。中→英可试「开会」或「我明天有个会」，英→中可试 `meeting`、`metting`、`meeetingg` 或 `He go to work.`。只有预设样例有对应结果，未命中不代表真实系统无法翻译；没有波浪线也不代表输入正确。

## 浏览器验证记录

已通过真实 Chrome 的点击、输入和按键操作观察以下行为，全部基于固定样例。

| 路径 | 观察结果 |
| --- | --- |
| 普通模式输入「你好」，按 Enter | 模拟宿主得到中文，没有学习片段 |
| 中→英输入「开会」，按 Enter | 模拟宿主直接得到 `have a meeting`，没有额外确认 |
| 英→中输入 `meeting` 后加空格 | 无预设错误标记，可选择「会议」上屏 |
| 英→中输入 `metting` | 加空格前无标记，加空格后出现波浪线；点击后显示说明，仍有「会议」候选 |
| 选择 `metting` 对应的中文候选 | 中文直接上屏，片段保留主动尝试与疑似问题来源 |
| 英→中输入 `meeetingg` 后加空格 | 有波浪线，无中文候选；Enter 保留输入，明确点击原文上屏后才提交英语 |
| 英→中输入 `He go to work.` | 按预设规则标记 `go`，点击只显示语法问题说明 |
| 聊天中保留「开会」，切到笔记再切回 | 两处模式、输入和上屏内容不串用，聊天中仍可继续选词 |
| Ctrl+Shift+K 来回切换模式 | 原模式输入可恢复，没有自动提交 |
| 双击波浪线单词并手动重输 | 能选中原词并自行修改，修改为 `meeting` 后预设标记消失 |
| 普通模式提交包含 HTML 标签的文字 | 模拟宿主按文字显示，没有创建对应 HTML 元素 |

六个引导场景也已逐一点击走通。内联 JavaScript 通过语法解析检查。

浏览器自动化工具不允许直接访问本地文件，因此交互操作通过仅绑定回环地址的静态服务进行。另用独立临时配置的无头 Chrome 验证了 `file://` 直接打开，页面状态和全部场景均正常渲染。直接文件验证不使用用户的真实 Chrome 配置。

## 方案选择与边界

比较了两种提示位置。独立错误区不必操作可编辑文字，但用户需要来回看输入与提示。当前原型采用行内波浪线，说明按需展开，候选仍可直接提交。这是建议方向，不代表已经证明最终产品更流畅。

按应用、模式和方向分开保存草稿，可以避免静默重新解释或误提交未完成输入，但用户切换后需要知道还有其他草稿。原型在状态栏列出它们，正式产品的提示方式尚未决定。

原型有以下限制。

- 不实现拼音转汉字，中文输入使用浏览器外的系统输入法。不证明真实组合输入兼容性。
- 不包含真实模型、拼写词典、语法检查器、模糊匹配或异步翻译。`metting` 可译、`meeetingg` 不可译是预设情形，不是模型评测结果。
- 不验证响应速度、冷启动、模型内存或翻译质量。
- 不连接其他应用，不验证 macOS 权限、输入法接入、宿主光标位置或系统快捷键冲突。
- 原生浏览器拼写检查已关闭，波浪线来自预设规则；不保证能识别任意输入的错误。
- 行内标记会局部重建编辑内容并恢复选区，尚未验证真实输入法组合、撤销历史和所有复杂编辑行为。
- 页面没有外部资源和业务联网请求，内容安全策略禁止连接外部服务。所有状态只在内存中，刷新会清空。
- 学习片段只演示来源区分和疑似问题，不实现正式存储、删除、误报排除或复习。片段各取源文和结果最多 24 个字符只是演示裁剪方式，不是已选定的记录策略。
- 按词或短语拼接结果不保证整句自然。正式句子输入和句级反馈仍需设计。

下一步先由使用者体验候选上屏和标记位置，再验证原生 macOS 输入法接入与离线组件，不直接把本原型提升为正式实现。
