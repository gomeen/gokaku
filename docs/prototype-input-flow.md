# 早期输入流程决策（原型已退役）

早期 `input-flow.html` 及两张截图已于 2026-11-08 从当前树删除。它使用固定样例探索候选直接上屏与英语问题提示，尚未实现拼音引擎、真实翻译或系统输入法；后来确认的规则已并入[产品方向](product.md)，旧页面及浏览器操作记录可从 Git 历史追溯。

保留的结论：

- 选中就绪目标后直接上屏，不增加一次翻译确认。
- 只对用户输入的英语标记疑似问题；点击说明，不自动修改。
- 翻译失败保留输入，原文上屏需要明确操作。
- 切应用、字段、模式或方向使旧请求与候选失效；模式和方向是全局偏好，草稿需要显式恢复。旧页面按模拟应用各自保存模式、切回自动恢复的演示已被后续裁决替代。

现役交互参考为[输入习惯原型](prototype-input-habits.md)，设置与皮肤以产品文档引用的定稿原型为准；实际能力及验证边界见[原生开发验收](validation/native-development.md)。
