# 翻译安全规则与资源边界

当前学习翻译只使用火山 NMT，默认关闭；具体产品合同见 [产品方向](product.md#翻译后端2026-11-06-双端统一计划)。未来接入其他在线模型时，继续复用请求身份、取消、超时、缓存隔离与失败保留输入规则，不恢复旧本地模型链路。

## 当前保留内容

- `shared/GogakuCore/translate/`：繁简、重复、时间／数字、品牌和输入保护等共享规则及其测试。结构检查不证明语义正确，不得把“非空输出”算作翻译质量通过。
- `resources/translation/`：表达、模板、品牌、选词清单和审核日志，保留清单哈希、署名与许可。这些仍被现行核心／构包和测试消费，不能随旧模型删除；资源存在不代表当前云翻译会使用每一条历史策略。
- `scripts/build-translation-expressions.py`：基于 CC-CEDICT、jieba 与既有英文词频的资源生成器。选词来自独立类别清单，不从测试失败样例补答案；多义项与人工改写保留来源和审核记录。
- `validation/` 及 `probes/translation-*.json`：提供商无关的合成考题、参考与风险审阅索引。数量和冻结身份由 `scripts/validate-translation-data.py` 离线核对，不自动调用云端，也不按参考字符串精确相等判断语义质量。

## 已退役内容

small100 生成＋quickmt 反向评分、λ 调参、多后端测速、模型准备与旧策略验收结果已经删除，可从 Git 历史追溯。旧覆盖率、延迟和模型排名不再进入现行发布测试，也不能用于宣称火山或未来在线提供商质量合格。

## 实际验收

- fast 运行通用数据检查、共享核心、Swift 调度及云 HTTP 离线假响应回归；不会上传用户输入或读取真实凭据。
- 实际服务质量需要授权凭据、少量双向调用与逐条语义审阅；请求成功与质量合格分开记录。
- 取消／失焦／方向或资源变化后，迟到结果不得恢复候选资格；失败保留可编辑原文，只有用户明确操作才原文上屏。
- 当前测试覆盖与尚未闭环的宿主、Windows、安装／升级和联网验收见 [清理与测试审查](validation/testing-cleanup-audit.md)。
