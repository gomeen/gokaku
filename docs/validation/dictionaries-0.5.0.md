# Gogaku 0.5.0 扩展词库验收

候选构建号为 128。公开发布记录仍以 0.4.1 为准。Mac 真实宿主、Windows 运行与在线渠道均未验收。

## 已取得的专项证据

- 共享核心的 `dict_import`、`dict_catalog`、`dict_mount` 通过。SCEL 夹具包含自造条目。对合成文件执行了 2,000 个固定种子的截断及变异输入。
- 2026-11-23 的开发 fast 通过 7/7 项，含 341 项 Swift 测试。ASan／UBSan quick 通过 2,000 个输入序列和三个词库核心测试。
- zhwiki 0.3.1 原始 `.dict` 包含 1,734,069 条，实测转换 13.88 秒。转换后 1,444,888 条。120 例普通输入的出厂词典结果为首选 109、前十 112，挂载转换后的 zhwiki 为首选 110、前十 113。
- catalog-1 的 13 个词库资产各重建一次，SHA-256 全部一致。THUOCL 成语表的 8,515 条与出厂词库重复，另有 4 条读音不唯一，因此按合同生成零条目的词库。其余 12 本生成非空词库。逐本报告随 `dist/dict-catalog/release-notes.md` 生成。
- 词库发布 dry-run 使用临时 Ed25519 测试密钥。生产钥匙使用发布环境。仓库查询未找到 `gomeen/gogaku-dicts`。生产签名、词库 Draft 和人工审阅均待完成。

## 定版门槛

真实按键宿主测试等待授权空闲时段。Windows 用户代理与设置应用的运行验收在本轮范围之外。zhwiki 300 条新词抽样、出厂抽样与性能指标单独记录。取得签名环境与发布权限并完成规则要求的发布审批前，0.5.0 保持本地候选状态。
