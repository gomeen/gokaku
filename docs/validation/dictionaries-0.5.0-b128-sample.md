# 0.5.0 b128 词库抽样与性能

使用共享核心 C ABI 在 Intel Mac 上离线测量普通全拼输入。使用固定种子 `20261126` 从已转换的 zhwiki 和出厂词典各抽 300 条；抽样池分别为 1,444,888 和 300,373 条可输入全拼条目。实际输入连续全拼字母，调频、英文补全和释义关闭。测量包含核心处理和候选快照生成。耗时为单次运行，宿主输入延迟另行验收。

| 样本 | 出厂首选 | 挂载首选 | 出厂前九 | 挂载前九 | 逐键 p95 变化 |
| --- | ---: | ---: | ---: | ---: | ---: |
| zhwiki | 67/300 | **240/300（80.0%）** | 67/300 | **297/300（99.0%）** | 3.347 → 3.257 ms |
| 出厂词 | 165/300 | **165/300（55.0%）** | 265/300 | 265/300 | 3.549 → 3.522 ms |

挂载 `apply` 实测 **0.152 ms**。词库文件 26,929,569 字节。进程在加载词库前及挂载后分别通过 `ps` 采样，RSS 增加 **28,426,240 字节（文件大小的 1.056 倍）**。测量时已验证并暂存资产，RSS 采样覆盖句柄加载与挂载。

达到抽样与性能门槛。新词首选要求 60%，前九要求 90%，出厂首选最多下降 1 个百分点，逐键 p95 最多增加 0.5 ms，`apply` 最多 5 ms，RSS 增量最多为文件大小的 2.2 倍。

zhwiki 资产 SHA-256 `2c465479555ca9c5a9646e3ef0990a22c218764634157fc8e58429cd0dd25b97`。本机原始结果在 `.build/dict-0.5-validation/sample-b128.json`。
