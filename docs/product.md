# 产品方向

Gogaku 让用户在日常输入中学习另一种语言。本文是已确认需求的依据；实施路线、阶段状态和证据见[首阶段实施总计划](implementation-plan.md)及[原生开发验收](validation/native-development.md)。

**当前已进入双端（macOS＋Windows）原生工程实施。当前发布基线为 `0.1.4 / b112 stable`：双端安装包已构建并发布，fast／release 自动化验证通过，发布清单签名已核验；真实 host 未运行且有明确豁免。** Mac 真实输入源、Windows b112 宿主、客户端在线更新 E2E、完整升级恢复／卸载和翻译凭据实测仍未完成。学习翻译保持火山 NMT、默认关闭、需用户保存凭据并显式启用；Windows 已交叉编译 x86／x64 TSF、x64 每用户代理、七页设置与更新客户端。b112 资产和发布身份见[发布记录](validation/release-b112.json)，b91 构包细节见[历史报告](validation/windows-setup-build.json)。构包不依赖 VM，历史 VM 证据只归属于对应构建。既有[浏览器原型](prototype-input-flow.md)仍只用预设样例，不能作为真实翻译能力。功能状态及未补齐项见[双端功能对照](feature-parity.md)。

**历史 b94 验收记录**：Chrome 字段切换时旧组合提交至新字段，扩大宿主验收不通过；安装／回滚／卸载未执行。这些记录用于说明历史缺陷和边界，不能作为 b112 当前状态。见[本轮验收](validation/dev-b94-acceptance/README.md)及[机器汇总](validation/dev-b94-acceptance.json)。

此前 dev b94 的 fast、默认升级和限定宿主记录保留在验证目录，作为历史回归材料；它们不代表当前 b112。

## 目标与范围

- 独立的语言学习输入法，同时面向零基础和已有基础用户，不要求先会目标语言才能使用。
- 产品允许不同母语与学习语言；首阶段覆盖当前 Intel Mac（macOS 26.7.2）与 Windows 11 x64（Windows 11，含 64 位与 32 位应用）的中文／英语双向，包括词、常用短语与完整句子。两端共享同一 C++ 业务核心；翻译统一经用户配置的火山 NMT，不随包本地模型。Windows ARM64、Windows 10、Apple Silicon 不在本轮范围。
- 性能优先保证真实输入过程：逐键响应、中文候选、目标质量、一次提交与焦点安全。设置和片段列表只做够用实现，其写盘不能阻塞输入。
- 核心离线可用，联网增强默认关闭；失败、超长或缺包不构成静默联网的理由。
- 不强制先练习或回忆；学习帮助不能妨碍用户完成输入。不做自动纠正、自动复习或掌握评分。

## 已确认的三种输入状态

| 状态 | 输入／输出 |
| --- | --- |
| 普通 | 小鹤双拼输入，中文上屏，不翻译 |
| 学习，中→英 | 小鹤生成中文来源，同屏选对应英语，一次上屏目标 |
| 学习，英→中 | 独立英语缓冲，选中文结果，只检查用户英语 |

小鹤指双拼，不是小鹤音形。英语不交给拼音引擎。模式与方向明确，不仅凭字母、拼音或文字自动改变方向；`can`等歧义不能用于自动切换。

所有状态统一使用**光标旁非激活浮动候选窗**作为主体。焦点留在宿主；候选与预编辑不写入宿主，只有确认上屏才执行宿主插入，不打开独立编辑器。普通模式默认在宿主正文用 marked text 附加显示正在输入的字母（输入区字母，见下节规格），这是对该默认裁决的补充反馈而非回到“宿主内联预编辑”方案；设置可关闭，关闭后回到纯浮动候选窗。

中文来源、目标与简短中文说明绑定、同屏；无需先确认中文再确认翻译。当前组合可以直接写整句，同一体验提供完整来源和可用词／短语候选。部分选择仅消费相应源范围，剩余继续编辑，已提交正文永不被后续结果改写。按词拼接的结果不能冒充整句自然度合格。

## 已确认的按键与模式切换

普通模式行为规格来自六轮输入习惯原型迭代（2026-10-31 用户裁决，含组合中标点一次上屏、数字 0、英文释义常显、输入区字母、按应用默认英文等；其中「组合中 Shift 不切英文」已被 2026-11-02 裁决替换为「原编码上屏并切英文直输」，见下表），以[输入习惯原型](prototype-input-habits.md)的演示为确认标准。本节是需求；工程实现状态见[实施总计划](implementation-plan.md)与[验收记录](validation/native-development.md)，未实现项不得标为已验证。

### 输入区字母显示的风险与缓解

默认在宿主正文直接显示输入字母依赖 marked text，不同宿主对其渲染、长度上限与提交行为不一致；安全输入字段不显示字母。Windows 的临时文本存储（`TS_SS_TRANSITORY`，含 Chromium）可能在通知组合终止前就把预编辑留在正文，因此仅在浮动候选窗显示编码，显式选词时才写正文；原生持久文本存储继续遵循「输入区字母」设置。组合终止后重新分配字段身份，旧草稿不得出现在新字段；宿主复用上下文、无法确认原字段时，旧草稿仅保留在内存，不提供跨字段恢复。缓解：设置可整体关闭；失焦、切换应用或输入源前先清空宿主中的字母，再保存内存草稿；宿主自行改写或丢弃 marked text 的情况记入兼容性限制，不强行覆盖。

应用、字段、模式、方向或输入源变化立即使旧请求和旧提交资格失效、隐藏面板。不自动提交、丢弃或带入新字段。未完成内容保留为原应用／模式／方向关联的内存草稿，不覆盖已有草稿。用户通过菜单显式恢复成新的组合，或取消／清空；不自动恢复、不落盘，进程退出即清除。

每次输入与插字前核对IMK client、活动进程、选区／光标；不能只看bundle ID。无法确认目标不插字，转草稿；无法满足安全条件的宿主路径不得宣称支持。

## 已确认的自定义词语

自定义词语仅在普通模式中文状态出现；临时英文、按应用默认英文与学习模式中不出现。

| 项 | 规格 |
| --- | --- |
| 短码短语 | 编码为 1–32 个小写字母，不含数字；内容为任意纯文本（可含空格、换行），最多 512 个 Unicode 标量，上屏保持原样。当前组合恰好等于编码、且没有暂存分段和大写原样字母时出现，不做前缀补全；与输入方案无关，小鹤与全拼共用 |
| 拼音词 | 内容为 1–16 个汉字，读音为每字一个规范全拼音节（如 `hui'yi`）；小鹤与全拼自动通用，模糊音生效；作为高权重词参与长句组句 |
| 排序 | 当前组合完整匹配时：短码短语最前，其次拼音词，再到英文候选与普通候选；同一编码多条按设置页中的顺序；不受调频影响；选择自定义词不触发调频学习 |
| 设置页 | 新增「自定义词语」页，分「短码短语」与「拼音词」两个列表；支持新增、编辑、删除、启用／停用、调整顺序；拼音词提供「自动读音」（用 libime 词库给出每字常用读音，可逐字修改）；校验非法编码、音节与超长内容并给出具体原因；保存后 1 秒内在输入法中生效 |
| 存储 | `~/Library/Application Support/Gogaku/custom-words.tsv`，UTF-8、带版本行、制表符分隔，转义规则写入文档；仅当前用户可读写、原子写入；文件损坏时备份并以空表启动，设置页提示；与调频数据分开存放，清空调频不影响自定义词；不导入鼠须管、青简或系统文本替换；内容不写日志、不联网；格式两端共用 |

## 已确认的拼写与翻译失败规则

只对英→中用户输入的英语标记疑似问题，中→英工具生成的英语不计用户错误。完成词后检查，编辑使旧范围失效，UTF-16范围与输入修订绑定；波浪线在自己的输入区域，点击只解释，不替换。首版只交付可靠拼写，语法尚未可靠时不启用。

网址、邮箱、代码形态、专名／品牌／缩写及自定义忽略词走免标记。词典未收录不直接等于错误。提示可忽略，不阻止继续输入或明确原文提交。

`metting`等疑似错拼的诊断与译文资格分开：只有火山返回且通过当前请求校验的译文才可作为候选；拼写诊断本身不提供可提交目标，翻译成功也不证明拼写正确。无法确认时保留输入与问题说明，不把模型猜测变成可靠候选。

失败、缺包、超长、取消、方向或资源变化时保留输入；旧结果不能提交，不静默截断、不静默改语种。原文上屏只由明确操作触发。

## 已确认的学习片段与隐私

默认仅记录**实际成功提交**的学习源表达、目标表达、方向、来源类别及疑似问题，不记录普通输入、预取、取消、未采用项或宿主周边正文。

| 行为／来源 | 含义 |
| --- | --- |
| 采用工具表达 | 获得过帮助，不代表掌握 |
| 用户输入学习语言 | 主动尝试；诊断单独记录 |
| 检查器问题 | 只是疑似，用户可排除误报 |
| 工具生成错误 | 工具缺陷，不记为用户学习错误 |

本地保留30天，`expiresAt = createdAt + 30天`，查询不返回过期项；启动及低优先级日常维护清理。提供查看、删除、暂停、排除应用与误报。删除、暂停、排除也作用于待写队列，迟到任务不得复活删除项。队列上限256，数据库锁／满盘不拖慢输入；明确显示未保存，不无限重试。

用户目录为 `~/Library/Application Support/Gogaku/`，设置、SQLite与公开语言包分开。不将片段扩为全系统键盘记录，不把开启联网增强理解为上传历史授权。安全或无法确认安全的路径不辅助、不记录；产品不申请全局监听／外部应用辅助功能树来绕过保护。日志不含原文、译文或可逆文本标识；文本缓存仅内存，≤1MiB、5分钟过期，失焦／隐私切换清理。

IMK插字结果不明时不自动重试、不记成功事件。当前开发输入源尚无验收过的成功确认链路，因此真实学习记录仍关闭；SQLite合成回归通过不能替代该链路。

## 设置页面规格（2026-11-03 定稿）

视觉按已选原型 `prototypes/settings-final.html` 落为原生 SwiftUI／AppKit 实现（不嵌入 HTML）；其余整体风格方案（settings-a-*、settings-display-*、settings-n2-*、learning-backend-*）为历史探索，不再作为实现依据，其 html 与截图已于 2026-11-07 的外围收敛中删除。macOS 设置窗口：约 200pt 左侧分类导航，右侧按「学习翻译、普通输入、自定义词语、皮肤、快捷键、学习与隐私、学习片段」七页组织；每页一个内容滚动区，底部固定状态栏显示保存中／已保存／失败及重试。默认窗口 1100×800，最小 1000×520（2026-11-05 皮肤页定稿调整，见[皮肤说明](skin-themes.md)），保留原生标题栏与系统明暗外观，青绿强调色（浅色 `#12996a`／深色 `#34c48c`）。版本信息旁提供「检查更新」，打开独立更新窗口。Windows 端使用简单的 Win32 设置应用，满足同等功能，不位于按键性能链。

设置页只负责显示和操作，不复制业务判断。设置应用只服务设置窗口：关闭最后一个窗口即退出，不在 Dock 常驻，也不留后台进程；退出前先把合并中的文本改动落盘（`.terminateLater` 等落盘完成）。删除各页副标题和重复说明文字，保留标签、必要错误、保存状态、功能未开放状态和可访问性名称。普通输入页：候选字号 12–16 整数滑块带刻度；输入区字母显示内容用「展开全拼／原始编码」分段控件；模糊音三列九项，无计数、无解释、无批量操作。界面可见不代表对应输入或记录链路已通过验收。

**应用列表**（按应用默认英文、学习与隐私排除共用同一套图标＋名称列表和可搜索添加弹层）：应用选择器在后台索引 `/Applications`、`/System/Applications`、`~/Applications`，按 bundle ID 去重，使用系统提供的名称和图标；支持通过文件选择器添加其他位置的 `.app`。默认英文列表每行有启用开关和移除；关闭后仍保留该行，重开设置不消失。排除列表加入即排除、移除即恢复，不常显 bundle ID，支持连续添加。两个列表是独立设置，共用组件不得串值。旧配置中未安装或无法解析的应用保留记录并显示通用图标，不静默删除；仅缺少名称时才以标识作显示回退。

**快捷键页**为 VS Code「键盘快捷方式」式表格：普通／学习、学习方向两个可配置命令统一纳入，支持搜索、按键过滤、全部／我修改的／冲突筛选，以及编辑（录制）、清除、恢复默认。固定操作按真实普通／学习语义展示且不可编辑。设置改动立即保存：普通选项、应用列表、有效快捷键改动立即提交，连续文本输入合并 300ms 后提交，失焦或关窗时提交剩余有效改动；仅成功落盘后发送变更通知。

**自定义词语**保留原生管理（新增／编辑／删除、启用／停用、排序、自动读音与校验），不提供直接编辑 TSV 的入口；页面用「短码短语／拼音词」分段、搜索框与紧凑列表（单行内容＋编码／读音＋启用状态，长内容省略）解决词多时的复杂感。编辑、删除、上移／下移放在选中行工具栏或右键菜单；双击打开既有编辑表单，完整内容只在表单内显示；表单保留「保存／取消」。搜索覆盖内容、编码和读音，不改变存储顺序；搜索时禁用排序。

**学习翻译页**只保留火山 NMT：启用开关（默认关闭）、Access Key ID／Secret Access Key 保存与移除、用户点击的连接测试、未配置／已配置／最近失败状态，以及「本机本月请求字符统计」。不再提供 Apple Translation、后端选择、beam、模型准备或下载入口；不随包模型、CT2、SentencePiece、PyTorch。凭据只写入本机 0600 文件，不进设置导出、主题包、日志或安装包。统计只代表本机成功请求，不宣称账户余额或官方免费额度。

**学习记录开关只保存偏好**，真实学习记录门禁（宿主安全链路未验收）不因此解除；学习片段页读取真实存储，原型的示例数据不进入生产数据。

## 已确认的候选窗皮肤（2026-11-05 定稿）

以 `prototypes/skin-settings-demo.html` 最后原型为准，设置新增「皮肤」页。一级不区分浅深主题槽；一个主题有浅深两套配色时跟随系统，只有一套时自动单色。内置 Gogaku、Claude、Grok Bot、女巫魔药，支持用户主题的新建、复制、编辑、删除、应用及 `.gogakutheme` 导入导出。

一级为左列表右预览，二级为左配置右固定预览，两级共用高度上限；中间竖线分隔，去掉两列额外圆角背景、滚动条、Tab 底部通长横线与重复提示。预览默认展开九条。编辑按「主题与字体、形状与间距、背景与透明度、颜色」分组，浅深编辑 Tab 与预览拉开间距。

名称和字体共用；颜色、圆角、内边距、行高、整体／背景色／背景图透明度及图片按外观保存。候选字号按定稿原型为主题级 12–24，序号 8–20；旧默认主题保留普通输入页全局 12–16 及历史渲染。主题不改变每页九条、候选选择、翻页或上屏规则。编辑先改草稿，保存与应用分别操作；未保存离开确认，写盘失败不伪报成功。

主题文件为纯数据，字体只引用本机字体，不捆绑第三方字体或图片。v1 为 ZIP 内唯一 `theme.json`，图片规范化后内嵌；范围、格式、安全边界和本轮工程取舍见[皮肤说明](skin-themes.md)。原生设置、持久化与离屏渲染已实现并回归；真实输入源外观／性能及完整宿主验收仍未完成，证据见[皮肤验收](validation/skin-native-status.md)。

## 已选工程路线与资源门槛

中文固定 **libime 1.1.17＋已测出厂数据＋Xiaohe**。业务核心迁移为共享 C++ 实现，两端通过同一版本化 C ABI 使用；macOS 端保留 Swift／InputMethodKit／AppKit 作为薄调用方，Windows 端以 C++／Windows SDK 实现 TSF 文本服务和 Win32 界面。不为跨平台引入 Flutter、Electron 或通用插件平台。不重新比较引擎，不复制青简或Fcitx整套前端，不导入其他输入法私人词库；中文调频默认开启，只学习普通模式完整上屏的中文，数据仅存本机，设置可关闭与清空。理由及既有证据见[选型决定](input-selection-decision.md)。

### 翻译后端（2026-11-06 双端统一计划）

- **只保留火山翻译（Volcengine NMT，TranslateText 2020-06-01）**，作为学习翻译的唯一后端。两端移除本地翻译模型功能：不再随包或下载 small100／quickmt 权重、CT2、SentencePiece、PyTorch，也不保留后端选择、beam、模型准备入口。旧工具、模型排名和运行结果已清理，历史可从 Git 追溯；通用测试输入与当前产品测试保留，不恢复已删除功能。
- 普通输入完全离线，不经过翻译进程。只有学习模式且设置开关开启时，才把学习源文发送到火山 API；不发送宿主周边正文、学习记录、设备标识或普通输入内容。
- 凭据独立存储，仅当前用户可读写（0600）；不进设置导出、主题包、日志或安装包。更换或移除凭据后，辅助进程按请求热读，不重建模型。
- 以隔离辅助进程运行（Mac 为随包 `GogakuTranslator --volcengine`；Windows 由每用户代理派发）；辅助进程无宿主写入权限。超时、断网、认证／权限错误、限流、余额问题、空结果和服务错误统一处理：保留可编辑输入、短暂提示，不自动提交原文、不自动切换语言、不弹窗打断；⌘Return（Windows Ctrl+Enter）明确原文上屏。
- 缓存仅内存（≤1 MiB、5 分钟过期、失焦清理）；预译与缓存命中不重复计量；失败不无限重试。Esc 取消；切字段／应用／方向使旧请求失效；迟到结果不得进入候选或恢复提交资格。
- 用户点击「连接测试」才发一次短请求；测试结果只显示成功／错误与耗时。本机「本月请求字符统计」只统计成功响应，优先使用服务端计费字符数；价格与免费额度不硬编码为长期保证。
- 质量口径：火山返回的译文属于外部服务输出，不以本地模型质量门槛替代审阅。成功结果才显示候选；失败保留输入。正式交付前必须用授权凭据做少量双向实测（签名、TLS、计量、失败类别）并由用户确认可用性；未配置凭据时绝不发送。
- 旧引擎／本地翻译模型选型工具、结果、依赖及展示页已退役，只保留采用理由、共享安全规则、通用翻译考题及现役输入法测试；详见[测试审查](validation/testing-cleanup-audit.md)。更换在线提供商后继续复用请求身份、超时／取消／缓存隔离和失败留输入的测试，另补提供商专属协议测试；这不是新提供商已实现的声明。

## 交付与验收边界

当前授权为双端开发测试版：Mac 当前用户安装、用户手动启用；Windows 11 x64 由安装向导完成一次 UAC 注册，不自动设默认输入法。保留其他输入源，不修改系统显示语言，不关闭安全机制，不强杀宿主、不擅自注销或重启。卸载默认保留数据；共用数据清理是显式操作。

**Mac 对外只交付 `.pkg`，不再生成或交付 DMG；Windows 交付 Inno Setup `.exe`。** 本轮不做 Apple Developer ID／公证、Windows Authenticode；未签名安装包的系统提示照实说明，不关闭系统安全机制。更新清单使用独立 Ed25519 签名，不把更新签名混称为系统代码签名。在线主题商店、学习记录采集解锁、更多架构和平台不在本轮范围。Gogaku 自身代码以 MIT 许可发布（仓库根 `LICENSE`）；第三方实际义务见[许可说明](third-party.md)。

### 检查更新

- 版本信息旁「检查更新」打开独立窗口；自动检查默认关闭，开启后在设置窗口打开期间按 24 小时最多尝试一次（关窗即退出设置应用，不驻留后台），失败不紧密重试。
- 使用 GitHub 公开 Releases 与签名清单；只接受正式 Release（stable 不读 prerelease），按构建号判断升级，不自动降级，stable／dev 互不自动切换。
- 下载与安装都由用户点击触发；下载后校验大小与 SHA-256，启动安装前再次校验。自动发现新版只在设置内提示，不抢输入焦点、不自动下载／安装／重启。
- 更新请求不携带输入内容、火山凭据、学习记录或设备唯一标识；未配置更新源的构建明确显示「未配置更新源」，不能显示「已是最新」。
