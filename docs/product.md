# 产品方向

Gogaku 让用户在日常输入中学习另一种语言。本文是已确认需求的依据；实施路线、阶段状态和证据见[首阶段实施总计划](implementation-plan.md)及[原生开发验收](validation/native-development.md)。

**当前已进入双端（macOS＋Windows）原生工程实施。Mac 普通输入已在独立 AppKit 宿主和 Orca 终端完成限定场景核验；完整宿主安全矩阵、Windows 端和双向学习产品均未通过。** Windows 11 x64 桌面环境是明确前置条件，未提供前不得把 Windows 或双端交付标为通过。核心／桥接测试、可构建程序和真实宿主证据分别记录。既有[浏览器原型](prototype-input-flow.md)仍只用预设样例，不能作为真实翻译能力。

## 目标与范围

- 独立的语言学习输入法，同时面向零基础和已有基础用户，不要求先会目标语言才能使用。
- 产品允许不同母语与学习语言；首阶段覆盖当前 Intel Mac（macOS 26.7.2）与 Windows 11 x64 的中文／英语双向，包括词、常用短语与完整句子。两端共享同一 C++ 业务核心与翻译模型，仅输入法前端和系统集成不同。
- 性能优先保证真实输入过程：逐键响应、中文候选、目标质量、一次提交与焦点安全。设置和片段列表只做够用实现，其写盘不能阻塞输入。
- 核心离线可用，联网增强默认关闭；失败、超长或缺包不构成静默联网的理由。
- 不强制先练习或回忆；学习帮助不能妨碍用户完成输入。不做自动纠正、自动复习或掌握评分。

## 已确认的三种输入状态

| 状态 | 输入／输出 |
| --- | --- |
| 普通 | 小鹤双拼输入，中文上屏，不翻译 |
| 学习，中→英 | 小鹤生成中文来源，同屏选对应英语，一次上屏目标 |
| 学习，英→中 | 独立英语缓冲，选中文结果，只检查用户英语 |

小鹤指双拼，不是小鹤音形。英语不交给拼音引擎。模式与方向明确，不仅凭字母、拼音或文字自动改变方向；`can`等歧义不能用于自动切换。

所有状态统一使用**光标旁非激活浮动候选窗**作为主体。焦点留在宿主；候选与预编辑不写入宿主，只有确认上屏才执行宿主插入，不打开独立编辑器。普通模式默认在宿主正文用 marked text 附加显示正在输入的字母（输入区字母，见下节规格），这是对该默认裁决的补充反馈而非回到“宿主内联预编辑”方案；设置可关闭，关闭后回到纯浮动候选窗。

中文来源、目标与简短中文说明绑定、同屏；无需先确认中文再确认翻译。当前组合可以直接写整句，同一体验提供完整来源和可用词／短语候选。部分选择仅消费相应源范围，剩余继续编辑，已提交正文永不被后续结果改写。按词拼接的结果不能冒充整句自然度合格。

## 已确认的按键与模式切换

普通模式行为规格来自六轮输入习惯原型迭代（2026-10-31 用户裁决，含组合中标点一次上屏、数字 0、英文释义常显、输入区字母、按应用默认英文等；其中「组合中 Shift 不切英文」已被 2026-11-02 裁决替换为「原编码上屏并切英文直输」，见下表），以[输入习惯原型](prototype-input-habits.md)的演示为确认标准。本节是需求；工程实现状态见[实施总计划](implementation-plan.md)与[验收记录](validation/native-development.md)，未实现项不得标为已验证。

### 输入区字母显示的风险与缓解

在宿主正文直接显示输入字母依赖 marked text，不同宿主对其渲染、长度上限与提交行为不一致；安全输入字段不显示字母。缓解：设置可整体关闭；失焦、切换应用或输入源前先清空宿主中的字母，再保存内存草稿；宿主自行改写或丢弃 marked text 的情况记入兼容性限制，不强行覆盖。

应用、字段、模式、方向或输入源变化立即使旧请求和旧提交资格失效、隐藏面板。不自动提交、丢弃或带入新字段。未完成内容保留为原应用／模式／方向关联的内存草稿，不覆盖已有草稿。用户通过菜单显式恢复成新的组合，或取消／清空；不自动恢复、不落盘，进程退出即清除。

每次输入与插字前核对IMK client、活动进程、选区／光标；不能只看bundle ID。无法确认目标不插字，转草稿；无法满足安全条件的宿主路径不得宣称支持。

## 已确认的自定义词语

自定义词语仅在普通模式中文状态出现；临时英文、按应用默认英文与学习模式中不出现。

| 项 | 规格 |
| --- | --- |
| 短码短语 | 编码为 1–32 个小写字母，不含数字；内容为任意纯文本（可含空格、换行），最多 512 个 Unicode 标量，上屏保持原样。当前组合恰好等于编码、且没有暂存分段和大写原样字母时出现，不做前缀补全；与输入方案无关，小鹤与全拼共用 |
| 拼音词 | 内容为 1–16 个汉字，读音为每字一个规范全拼音节（如 `hui'yi`）；小鹤与全拼自动通用，模糊音生效；作为高权重词参与长句组句 |
| 排序 | 当前组合完整匹配时：短码短语最前，其次拼音词，再到英文候选与普通候选；同一编码多条按设置页中的顺序；不受调频影响；选择自定义词不触发调频学习 |
| 设置页 | 新增「自定义词语」页，分「短码短语」与「拼音词」两个列表；支持新增、编辑、删除、启用／停用、调整顺序；拼音词提供「自动读音」（用 libime 词库给出每字常用读音，可逐字修改）；校验非法编码、音节与超长内容并给出具体原因；保存后 1 秒内在输入法中生效 |
| 快速添加 | Control＋Shift＋A（设置可改）把当前应用、当前输入框 60 秒内最近一次完整上屏的中文候选连同实际拼音加为拼音词，提示「已加入「…」」或「已存在」；不打断打字。原编码上屏、标点、英文、学习模式结果、安全输入状态与排除应用不可添加；没有可添加内容时该快捷键交还宿主 |
| 存储 | `~/Library/Application Support/Gogaku/custom-words.tsv`，UTF-8、带版本行、制表符分隔，转义规则写入文档；仅当前用户可读写、原子写入；文件损坏时备份并以空表启动，设置页提示；与调频数据分开存放，清空调频不影响自定义词；不导入鼠须管、青简或系统文本替换；内容不写日志、不联网；格式两端共用 |

## 已确认的拼写与翻译失败规则

只对英→中用户输入的英语标记疑似问题，中→英工具生成的英语不计用户错误。完成词后检查，编辑使旧范围失效，UTF-16范围与输入修订绑定；波浪线在自己的输入区域，点击只解释，不替换。首版只交付可靠拼写，语法尚未可靠时不启用。

网址、邮箱、代码形态、专名／品牌／缩写及自定义忽略词走免标记。词典未收录不直接等于错误。提示可忽略，不阻止继续输入或明确原文提交。

`metting`等疑似错拼的诊断与译文资格分开：只有命中审核过的容错表达，才提供对应可提交目标；否则保留输入与问题说明，不把模型猜测变成可靠候选。翻译成功不证明拼写正确，诊断也不证明译文可靠。

失败、缺包、超长、取消、方向或资源变化时保留输入；旧结果不能提交，不静默截断、不静默改语种。原文上屏只由明确操作触发。

## 已确认的学习片段与隐私

默认仅记录**实际成功提交**的学习源表达、目标表达、方向、来源类别及疑似问题，不记录普通输入、预取、取消、未采用项或宿主周边正文。

| 行为／来源 | 含义 |
| --- | --- |
| 采用工具表达 | 获得过帮助，不代表掌握 |
| 用户输入学习语言 | 主动尝试；诊断单独记录 |
| 检查器问题 | 只是疑似，用户可排除误报 |
| 工具生成错误 | 工具缺陷，不记为用户学习错误 |

本地保留30天，`expiresAt = createdAt + 30天`，查询不返回过期项；启动及低优先级日常维护清理。提供查看、删除、暂停、排除应用与误报。删除、暂停、排除也作用于待写队列，迟到任务不得复活删除项。队列上限256，数据库锁／满盘不拖慢输入；明确显示未保存，不无限重试。

用户目录为 `~/Library/Application Support/Gogaku/`，设置、SQLite与公开语言包分开。不将片段扩为全系统键盘记录，不把开启联网增强理解为上传历史授权。安全或无法确认安全的路径不辅助、不记录；产品不申请全局监听／外部应用辅助功能树来绕过保护。日志不含原文、译文或可逆文本标识；文本缓存仅内存，≤1MiB、5分钟过期，失焦／隐私切换清理。

IMK插字结果不明时不自动重试、不记成功事件。当前开发输入源尚无验收过的成功确认链路，因此真实学习记录仍关闭；SQLite合成回归通过不能替代该链路。

## 设置页面规格（2026-11-03 定稿）

视觉按已选原型 `prototypes/settings-final.html` 落为原生 SwiftUI／AppKit 实现（不嵌入 HTML）；其余整体风格方案（settings-a-*、settings-display-*、settings-n2-*）为历史探索，不再作为实现依据。macOS 设置窗口：约 200pt 左侧分类导航，右侧按「语言资源、普通输入、自定义词语、快捷键、学习与隐私、学习片段」六页组织；每页一个内容滚动区，底部固定状态栏显示保存中／已保存／失败及重试。默认窗口 900×620，最小 760×520，保留原生标题栏与系统明暗外观，青绿强调色（浅色 `#12996a`／深色 `#34c48c`）。Windows 端使用简单的 Win32 设置应用，满足同等功能，不位于按键性能链。

设置页只负责显示和操作，不复制业务判断。删除各页副标题和重复说明文字，保留标签、必要错误、保存状态、功能未开放状态和可访问性名称。普通输入页：候选字号 12–16 整数滑块带刻度；输入区字母显示内容用「展开全拼／原始编码」分段控件；模糊音三列九项，无计数、无解释、无批量操作。界面可见不代表对应输入或记录链路已通过验收。

**应用列表**（按应用默认英文、快速添加排除、学习与隐私排除共用同一套图标＋名称列表和可搜索添加弹层）：应用选择器在后台索引 `/Applications`、`/System/Applications`、`~/Applications`，按 bundle ID 去重，使用系统提供的名称和图标；支持通过文件选择器添加其他位置的 `.app`。默认英文列表每行有启用开关和移除；关闭后仍保留该行，重开设置不消失。排除列表加入即排除、移除即恢复，不常显 bundle ID，支持连续添加。三个列表是独立设置，共用组件不得串值。旧配置中未安装或无法解析的应用保留记录并显示通用图标，不静默删除；仅缺少名称时才以标识作显示回退。

**快捷键页**为 VS Code「键盘快捷方式」式表格：普通／学习、学习方向、快速添加三个可配置命令统一纳入，支持搜索、按键过滤、全部／我修改的／冲突筛选，以及编辑（录制）、清除、恢复默认。固定操作按真实普通／学习语义展示且不可编辑。设置改动立即保存：普通选项、应用列表、有效快捷键改动立即提交，连续文本输入合并 300ms 后提交，失焦或关窗时提交剩余有效改动；仅成功落盘后发送变更通知。

**自定义词语**保留原生管理（新增／编辑／删除、启用／停用、排序、自动读音与校验），不提供直接编辑 TSV 的入口；页面用「短码短语／拼音词」分段、搜索框与紧凑列表（单行内容＋编码／读音＋启用状态，长内容省略）解决词多时的复杂感。编辑、删除、上移／下移放在选中行工具栏或右键菜单；双击打开既有编辑表单，完整内容只在表单内显示；表单保留「保存／取消」。搜索覆盖内容、编码和读音，不改变存储顺序；搜索时禁用排序。

**语言资源页**不再提供 Apple Translation 查询和安装入口（Apple Translation 已退出正式交付链路）；页面展示实际随包资源状态及「学习功能尚未开放」，不把实验缓存或已下载模型写成可用。

**学习记录开关只保存偏好**，真实学习记录门禁（宿主安全链路未验收）不因此解除；学习片段页读取真实存储，原型的示例数据不进入生产数据。

## 已选工程路线与资源门槛

中文固定 **libime 1.1.17＋已测出厂数据＋Xiaohe**。业务核心迁移为共享 C++ 实现，两端通过同一版本化 C ABI 使用；macOS 端保留 Swift／InputMethodKit／AppKit 作为薄调用方，Windows 端以 C++／Windows SDK 实现 TSF 文本服务和 Win32 界面。不为跨平台引入 Flutter、Electron 或通用插件平台。不重新比较引擎，不复制青简或Fcitx整套前端，不导入其他输入法私人词库；中文调频默认开启，只学习普通模式完整上屏的中文，数据仅存本机，设置可关闭与清空。理由及既有证据见[选型决定](input-selection-decision.md)。

翻译采用两端统一的 `alirezamsh/small100`（固定 revision `8ab680e26a596d2e3d2d2d17ae0f68df1037328c`）＋CT2 INT8、greedy、batch=1、2 线程；**Apple Translation 已退出正式交付链路**，设置页不再把安装 Apple 语言资源作为学习功能前置。两端用相同模型产物、分词和语言标记；同一权重在不同 CPU 后端不保证逐字一致，分别跑同一验收集并审阅差异，不制造假一致。任一端质量、离线或性能不合格，双端学习交付保持阻塞；不改成一端 Apple、一端其他模型，不恢复OPUS／M2M100，不扩大名单，不用固定译文演示交付。词／表达包拟采用审核CC-CEDICT义项及Tatoeba直接句对，逐条来源／许可；不自动倒置释义，不打包授权链未清的ECDICT。

翻译推理使用隔离的本地辅助进程（Mac）或每用户代理（Windows），不把 PyTorch／转换环境装入输入法进程；代理无宿主写入权限。质量复用32条风险回归，另每方向100条保留集在看输出前冻结，预标应译／应保留。应译可用率≥95%，固定关键风险不得有未处置意义破坏进入默认结果；空输出、超时、重复计失败。用户审阅盲测、参考和分歧后最终确认。缺合格双向资源就不能宣布完整学习产品完成。

## 交付与验收边界

当前授权为本机开发版、当前用户安装、用户手动启用；保留其他输入源，不自动设默认，不关闭安全机制，不擅自注销或重启。卸载默认保留学习数据，显式清理另行确认。公开分发、其他架构、Developer ID／公证和自动更新不在本轮范围，Gogaku项目许可仍未决定；第三方实际义务见[许可说明](third-party.md)。

完整通过依赖**两端**普通输入安全、合格统一模型与资源、学习交互、记录隐私、安装恢复及用户质量确认。Mac 覆盖 TextEdit／Notes、Chrome／Safari、Terminal及一个已有Electron宿主；Windows 覆盖记事本、Chrome、Windows Terminal 及一个 Electron 宿主。三状态实测；合成输入核对最终正文、选区、焦点、候选身份、记录与耗时。不同 OS 的焦点判定和提交协议分别验收，不能复用 Mac 通过状态；缺设备或未验证路径列未测，不能据核心／受控客户端结果宣称支持。

性能门槛和完整失败矩阵统一见[实施总计划](implementation-plan.md)。任何丢字、重复、串宿主、泄露或静默改文先暂停修复。已完成普通输入工程可单独交付，但不得改称完整学习产品。
