# 离线翻译基线实验方案

本轮要决定的是：在本机 Intel Mac、固定双向合成输入、batch=1 的条件下，哪些模型与推理配置值得进入原生输入法验证。不是给青简、Rime 或整个输入法宣布性能冠军，也不声称覆盖所有可选模型。

## 决策规则

- 先审阅译文，再看速度。丢否定、改日期数字、擅改网址或明显编造内容的结果不能仅凭低延迟胜出。生成成功不等于译文正确。
- OPUS-MT 两个单向模型作为小型专用基线，M2M100 418M 作为独立双向模型。它们不是来自青简或 Rime 的翻译实现。
- 比较 CTranslate2 CPU 的 FP32 与 INT8，以及 PyTorch CPU。PyTorch 报告 MPS 可用时，单独试跑 FP32 与 FP16，不默认 Intel 无 GPU 路径，也不因 API 可用就视为推理成功。
- 线程数为 1、2、4、8 的候选配置；GPU 另记。先用小样例筛查并调参，再对可运行配置交错重复测量。调参样例不作为最终性能结论。
- 如果差异小于轮次波动，或不能解释限速因素，结论写为不确定。未调优、异常退出和超时不能作为“更快”的证据。
- 此次性能选择只覆盖真实翻译调用，不包括中文解码、候选 UI、IMK 或宿主插入。其他输入引擎候选见[候选路线](input-engine-candidates.md)。

## 固定输入与计时边界

样本在 [translation-cases.json](../probes/translation-cases.json)，英语与中文各 16 条，覆盖孤立词、短语、短句、否定、时间、名称、错拼、未知词、网址和品牌版本。它们是自行编写的合成检查样例，不是通用翻译质量数据集。

调参子集为 `en-word`、`en-sentence`、`zh-word`、`zh-sentence`。主重复计时子集为 `en-word`、`en-phrase`、`en-sentence`、`en-negation`、`en-long`，以及对应的 `zh-word`、`zh-phrase`、`zh-sentence`、`zh-negation`、`zh-long`。

- 每请求一个输入，batch=1，不用批量吞吐冒充按键后的响应。
- 主调用计时包括分词、语言标记、张量准备、完整自回归生成、目标解码；MPS 在计时结束前同步，CTranslate2 实际消费 hypotheses。
- 子阶段分别记录 encode、generate、decode。计时不包括下载、转换、进程启动、模型加载和额外的人工质量审阅。
- 单独记录模型加载、首个请求、预热请求及进程峰值 RSS。每个配置首次加载发生在新进程，但文件系统可能已有缓存，不称为清空 OS 缓存后的冷启动。正式热推理比较用 `--keep-workers` 保持各配置模型驻留，轮次间交错请求；`ready_reused` 区分复用进程，不能把同一加载记录重复统计成多次冷启动。
- 同一模型对比使用相同语言控制、源 token 与生成参数。主比较采用 greedy，另行比较 beam=4 时明确分组，不把 beam 不同导致的质量与速度混为同一变量。
- 最大生成长度为 96 token。达到上限、空输出、加载错误、运行异常与超限输入单独计数，不静默截断或把错误行计入成功延迟。
- 原始权重、转换产物、模型卡许可、版本与 SHA256 记录在隔离目录；模型、依赖不进入产品仓库。

## 重复与干扰

正式比较至少五轮，按固定随机种子交错配置和样本顺序。记录每轮结果的中位数与范围，并保留请求级记录。单条请求来自不同长度分布，不能只合成一个数字后忽略词与句子的差别。

本机存在其他活跃应用，不停止用户进程。每轮记录系统负载与 CPU 活动；交错顺序只能减轻干扰，不能消除热节流或后台负载。小差距保留不确定，不外推到 M 系列或其他设备。

推理配置在独立子进程运行。CTranslate2 还使用不安装 PyTorch 的独立 venv，因为其包初始化会导入转换模块，间接导入可用的 PyTorch；仅声明不用 Torch 的 tokenizer 环境变量不足以避免不同 OpenMP runtime 同时加载。保留原始失败记录，不启用 `KMP_DUPLICATE_LIB_OK` 绕过冲突。模型转换用单线程，转换时间不进入推理比较。生产配置可以不同，不能把这次 Python 探针的全部内存直接归因于未来原生实现。

## 验证与限速证据

先做可运行性和质量冒烟，保存输入、完整输出、token 数与错误。再调线程、重复计时、另开不计入成绩的采样运行，区分生成计算、Python 调度、分词或其他瓶颈。

运行时只从本地路径加载，使用 offline 标志并在受限进程中复验无网络启动与实际推理。它与上一轮系统服务探针不同，不能把仅设置环境变量称为物理断网。

最终报告列出实测范围、失败配置、质量问题、计时边界、重复次数、波动、内存口径和未完成项。若没有合格配置，输出“不足以选型”，而不是把最快的错误翻译当作推荐。
