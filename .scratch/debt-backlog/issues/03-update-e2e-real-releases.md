# 03 客户端在线更新 E2E（真实 GitHub Releases 闭环）

Status: ready-for-agent

来源：[实施计划](../../../docs/implementation-plan.md)「八、测试与验收」更新安装节；P5 行「客户端真实旧版更新闭环未验证」。

## 背景

两端客户端、签名清单合同与发布脚本已实现，b110 与 0.5.0 发布侧均完成（Ed25519 清单签名已验证），但「旧版客户端 → 发现新版 → 下载 → 校验 → 安装 → 重开显示新版本」从未用真实 GitHub Releases 走通过。Windows 客户端从未运行过。

## 验收标准

- 以两个已发布构建验证：旧版发现新版、安装、重开显示新版本、数据保留、失败恢复。
- 真实 GitHub Releases 链路：获取（分页）、下载、SHA-256 校验、签名验证、安装交接。
- 失败路径回归仍过：离线、超时、校验失败、未知 schema、取消、磁盘不足。
- 未完成前不在任何文档标「在线更新已验收」。
