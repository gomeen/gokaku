# 06 旧设置写回迁移（schema 1→2 规范写盘）

Status: ready-for-agent

来源：[实施计划](../../../docs/implementation-plan.md)「已知缺口（未修，不阻塞）」段。

## 背景

规范化只发生在读侧：旧 schema 1 文件在 Mac 上读到的是「学习翻译关闭」，但文件本身仍是 schema 1；合并写盘只写差异字段，旧文件可能长期不被升级。降到旧版本阅读同一文件时会看成开启——语义漂移。

## 验收标准

- 设置应用读到 `migrated=1` 时做一次规范写盘（写侧迁移），文件升级为 schema 2。
- 写侧迁移单独验收：写盘失败恢复、原子替换、非 ASCII 路径；不在读契约里做副作用。
- 两端同一实现（属共享契约），同一组迁移向量双端共跑。
- 覆盖场景：旧本地模型配置、已启用火山配置、损坏文件、降级再升级往返。
