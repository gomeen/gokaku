# 04 Windows 完整升级恢复／卸载矩阵与旧版本自动清理

Status: ready-for-agent

来源：[实施计划](../../../docs/implementation-plan.md)「Windows：完整 Setup.exe」；P4 行「故障矩阵与旧版本清理待补齐」；[功能对照](../../../docs/feature-parity.md)「升级与恢复」「卸载与数据」行。

## 背景

版本目录、当前／上一根指针、注册失败恢复已实现；b94 默认升级、既有自启动迁移与数据保留通过（历史证据）。但完整故障恢复／卸载矩阵未跑，旧版本自动清理未实现。已知阻塞：隔离夹具曾在预检被 Defender 阻止。

## 验收标准

- 实现旧版本自动清理（保留上一版本恢复窗口，宿主释放后再清理）。
- 矩阵：升级失败恢复、卸载重装、锁定 DLL 升级、双通道并存、注销重登、管理员与标准用户发起。
- 升级失败不先删除唯一可用副本；卸载对称撤销注册、默认保留数据。
- Defender 阻挡夹具的问题需先解决或改用真实机验证。
